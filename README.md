Titanic Data Cleaning and Preprocessing

Project Overview

A Python-based data science project focused on cleaning and preprocessing the Titanic dataset to improve data quality and prepare it for further analysis.

Objectives

- Explore the dataset and generate basic statistical summaries.
- Handle missing values using median and mode imputation.
- Encode categorical variables using Label Encoding and One-Hot Encoding.
- Visualize passenger age distribution using Matplotlib and Seaborn.
- Export the cleaned dataset as a CSV file.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

Dataset

Source: "Kaggle – Titanic Dataset" (https://www.kaggle.com/competitions/titanic/data)

Key Outcomes

- Improved data quality by handling missing values.
- Converted categorical features into numerical representations.
- Visualized passenger age distribution.
- Generated a cleaned dataset for further analysis.

Conclusion

This project demonstrates essential data preprocessing techniques, including missing-value treatment, categorical encoding, and data visualization using Python.
